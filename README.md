# 30 Days of Power BI 📊

My 30-day Power BI challenge — one dashboard a day, one business problem solved, using real-world datasets. Built while preparing for Data Analyst roles.

## 🎯 About This Challenge

Each day, I tackle a new business problem using Power BI — from data cleaning in Power Query, to data modeling, to writing DAX measures, to building interactive visuals. The goal is consistent, hands-on practice and a growing portfolio that reflects real analyst work, not just polished templates.

## 🗂️ Primary Dataset

An AdventureWorks-style relational dataset used across most days:
- `cust_info` — customer demographics
- `prd_info` — product catalog & pricing history
- `sales_details` — transactional sales records

Some days may use additional/different datasets — noted in that day's write-up.

## 🛠️ Tools & Skills Practiced

- **Power Query** — data cleaning, transformation, merging tables
- **Data Modeling** — star schema, relationships between fact/dimension tables
- **DAX** — measures, calculated columns, aggregations
- **Visualization** — KPI cards, trend lines, bar/donut charts, slicers, drill-downs
